> **Status:** Planned · **Target Start:** Sep 10–15, 2026

## Context

After completing the core 150 problems with strong pattern mastery, selectively add 30–40 advanced problems that fill real gaps — not the full 250 mechanically.

## Selection Criteria

Pick problems that:
1. Test patterns NOT covered in the 150 (new algorithms)
2. Are harder variants of patterns you struggled with in revision
3. Appear frequently in target company interviews
4. Build on Stack Mastery topics (system-design-adjacent data structures)

## Candidate Problem Pool (curate at trigger time)

### DP Extensions (8–10 problems)
- Knapsack variants (0/1, unbounded, fractional)
- DP on trees
- Bitmask DP
- State machine DP (stock problems family)
- Digit DP (if targeting competitive)

### Graph Algorithms (5–6 problems)
- Bellman-Ford (negative weights)
- Floyd-Warshall (all-pairs shortest path)
- Bipartite checking
- Eulerian path
- Strongly Connected Components (Tarjan's)
- Minimum Spanning Tree variants

### Advanced Data Structures (5–6 problems)
- Segment Tree (range queries)
- Binary Indexed Tree / Fenwick Tree
- Trie variants (XOR trie, bitwise)
- Disjoint Set Union (advanced)
- Monotonic Queue advanced patterns

### Greedy & Intervals (5 problems)
- Activity selection variants
- Sweep line algorithms
- Scheduling with deadlines
- Huffman coding style problems

### Contest-Style Speed Drills (5 problems)
- Problems selected from recent LeetCode contests
- Focus on reading comprehension + fast implementation
- Time-boxed: 20 min per problem max

## How to Add to Tracker

When triggered, I'll:
1. Assess your revision data — which categories have "Struggled" resets
2. Check Pattern Health — which categories went red/yellow repeatedly
3. Cross-reference with the 250 list to pick the most valuable fills

5. Integrate into the same revision pipeline with difficulty-weighted intervals

## Success Metrics

Phase 2 is complete when:
- 30–40 problems solved with at least redo 2/4 on each
- No category in Pattern Health stays red for > 5 days
- Weekend Mock pass rate > 75% (3/4 solved clean in 90 min)
- Can explain any pattern from memory in < 2 minutes

## What NOT to Do

- Don't add all 100 remaining from 250 — most are redundant variants
- Don't prioritize Math/Geometry (rarely asked, low ROI)
- Don't add problems before the 150 revision pipeline is stable
- Don't sacrifice Stack Mastery time for more DSA grinding
